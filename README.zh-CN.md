# EarPose

[English](README.md) | **中文**

戴上 AirPods（或其他支持头部追踪的耳机），用转头控制 Mac：移动鼠标，或发出方向键玩游戏。不开摄像头，姿态数据只留在这台电脑上。

EarPose 在菜单栏里，没有程序坞图标。

[下载 EarPose.dmg](https://github.com/Zhang-BigSmart/EarPose/releases/download/v0.0.1/EarPose.dmg)

## 你需要什么

- **macOS 14** 或更新（Intel 和苹果芯片都可以）
- 支持头部追踪的耳机，并设为 Mac 的声音输出。已在 **AirPods Pro（初代）**、**AirPods 4 主动降噪** 上用过
- 两个系统权限：**运动与健身**、**辅助功能**

## 安装

1. 下载 **[EarPose.dmg](https://github.com/Zhang-BigSmart/EarPose/releases/download/v0.0.1/EarPose.dmg)**，双击打开。
2. 把 **EarPose** 拖到旁边的 **Applications（应用程序）**。
3. 打开「应用程序」。**不要双击。** 按住 Control 再点 EarPose（或右键）→ **打开** → 对话框里再点 **打开**。

系统可能会说「无法验证开发者」。这是正常的：目前没有经过苹果公证。只允许打开 **这一次 EarPose** 即可。不要去开「允许任何来源」，也不要关掉整台 Mac 的应用检查。

如果还是被拦：打开 **系统设置 → 隐私与安全性**，往下翻到安全性，点 **仍要打开**。

4. **系统设置 → 隐私与安全性 → 辅助功能**，打开 **EarPose**。必须是「应用程序」文件夹里那一份。
5. 戴上耳机，设为 Mac 的音频输出。点菜单栏 EarPose 图标 → **开始**。第一次会问「运动与健身」，选允许。

装了新版本以后，如果菜单还说辅助功能未允许，把 EarPose 的开关关掉再打开一次。

## 怎么用

点屏幕右上角菜单栏里的 EarPose 图标（没有程序坞图标）。

1. 戴上兼容耳机
2. 选控制方式：**指针** 或 **方向键**
3. 点 **开始**
4. 正对屏幕。指针感觉偏了就点 **重新校准**
5. **暂停** 只停头控，程序还在；**退出** 才关掉

| 快捷键 | 作用 |
| --- | --- |
| Control-Option-Command-H | 开始 / 停止 |
| Control-Option-Command-R | 重新校准 |
| Control-Option-Command-P | 暂停 |

玩游戏时，先点一下游戏窗口，方向键才会进到游戏里。

### 指针（激光笔）

- 转头：指针跟到主屏幕上对应的位置
- 短点头：鼠标左键
- 低头看键盘一小会儿：头控暂停，抬头后恢复
- 用手动机或触控板：头控会让开大约一秒
- 灵敏度滑杆：数字越小越灵敏

### 方向键（游戏）

- 甩过头会发出一次方向键，停在那里不会连发
- 每发一次，在中间停一下再甩下一次
- 这个模式**不会动鼠标**，鼠标仍用手控
- 点头不会变成按键。网页游戏请先用手按空格开局
- 先点一下游戏窗口，方向键才会进去。然后：选方向键 → 开始 → 重新校准 → 转头玩
- 适合「甩一下、回正再甩」的在线游戏：
  - [Google 贪吃蛇](https://www.google.com/fbx?fbx=snake_arcade) — 最好上手。空格开局，然后转头转向
  - [Google Pac-Man](https://www.google.com/logos/2010/pacman10-i.html) — 同样甩头改方向，在迷宫里吃豆
  - [2048](https://play2048.co/) — 每步甩一次，不拼手速
- 按住方向键转向的赛车现在还不支持：EarPose 是点一下键，不会按住

耳机过蓝牙传姿态会有一点延迟，休闲游戏更合适，别指望高难关卡。

这和系统自带的「头部指针」不是一回事。系统那套用摄像头看脸。EarPose 读的是耳机里的传感器，暗光也能用，也不占摄像头。

## 常见问题

**菜单栏没有图标**  
可能藏在 `»` 后面。或者再打开一次「应用程序」里的 EarPose。

**菜单说辅助功能没开，但设置里已经打开了**  
开关可能勾的是旧文件。只保留「应用程序」里的 EarPose，然后把开关关再开。

**点开始显示断开**  
请连上耳机、设为声音输出，并戴在耳朵上。有的电脑（尤其部分 Intel）读不到耳机运动。这时应显示断开，而不是闪退。

**头控和鼠标打架**  
指针模式下，动一下鼠标，头控会停一会儿。方向键模式不会去抢鼠标。

**安全**  
EarPose 发出的是真正的鼠标点击和键盘按键。出问题就点暂停。输密码、确认付款时不要开着头控。
